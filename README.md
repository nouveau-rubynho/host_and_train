# host_and_train

Lokalno gostovanje in fino uglaševanje modela **Ministral 3** (Apache 2.0) za uporabo kot
orkestrator pametnega doma.

- **Gostovanje** — Ministral 3 (3B / 8B) lokalno, z OpenAI-združljivim vmesnikom.
- **Učenje** — LoRA / QLoRA cevovod za tool-calling, z gradnikom in validatorjem podatkovne množice.
